# alexaroffCoachChess

Десктоп-приложение для macOS — шахматный **тренер** (Coach), который работает поверх доски на экране.  
Главная цель — **Duolingo Chess**.

## Цель проекта

Давать точные стрелки-подсказки в реальной партии:
- Игрок всегда сидит снизу
- Можно играть и белыми, и чёрными
- Система должна правильно понимать, чей сейчас ход
- Stockfish (~3000 Elo) используется только как источник сильного хода

Режим Auto (автоигра) в коде есть, но сейчас **не приоритет**.

### Как запускать сейчас

```bash
cd ~/alexaroffCoachChess          # или твой путь
source venv/bin/activate
pip install pyautogui             # если ещё не стоит
python main.py
```

При «Выбрать область…» в терминале появятся инструкции:
1. Навести мышь на левый верхний угол доски → Enter
2. Навести на правый нижний угол → Enter

## Важные решения по логике

- Игрок всегда внизу доски.
- Когда играешь чёрными — белые ходят первыми. Система должна увидеть ход белых, потом предлагать ответ.
- Главное узкое место — качество зрения, а не сила Stockfish.
- Маленькая быстрая модель (TinyCNN) для real-time на M2 8 ГБ.
