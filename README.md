# alexaroffCoachChess

Десктоп-приложение для macOS — шахматный **тренер** (Coach), который работает поверх доски на экране.  
Главная цель — **Duolingo Chess**.

## Цель проекта

Давать точные стрелки-подсказки в реальной партии:
- Игрок всегда сидит снизу
- Можно играть и белыми, и чёрными
- Система должна правильно понимать, чей сейчас ход
- Stockfish (~3000 Elo) используется только как источник сильного хода

Режим Auto (автоигра) в коде есть, но сейчас **не приоритет**.

## Текущий статус (26 июля 2026)

### Что уже сделано

- Полностью рабочий прототип: захват экрана, выбор области, фиксация ориентации, Stockfish, overlay со стрелками, hybrid reconcile.
- Подход на template matching был тщательно протестирован и **отброшен** — он не способен стабильно держать позицию после нескольких ходов на стилизованной доске Duolingo.
- Принято решение переходить на **нейросеть** для распознавания фигур (Вариант A).

### Датасет

Синтетический датасет уже сгенерирован из чистых шаблонов фигур Duolingo:

```
dataset/
  wP/ wN/ wB/ wR/ wQ/ wK/
  bP/ bN/ bB/ bR/ bQ/ bK/
  empty/
```

- Всего: **4600 изображений** (по 350 на каждую фигуру + 400 empty)
- Папка: `dataset/` в корне проекта
- Скрипт генерации: `generate_synthetic_dataset.py`

### Скрипт обучения (готов)

Файл: `train_piece_classifier.py`

Он делает два этапа:

1. **Учитель** — дообучает MobileNetV3-Small на синтетическом датасете
2. **Ученик** — очень маленький собственный CNN, который обучается через knowledge distillation от учителя

После запуска скрипта появятся файлы:

```
models/
  teacher_mobilenet_v3_small.pt
  student_tiny_cnn.pt
  class_names.json
```

### Следующие конкретные шаги

1. Запустить обучение:
   ```bash
   pip install torch torchvision
   python train_piece_classifier.py
   ```
2. Посмотреть точность (val_acc) учителя и ученика.
3. Встроить лучшую модель (скорее всего ученика) в `board_detector.py` вместо старого template matching.
4. Протестировать на реальных партиях Duolingo (и за белых, и за чёрных).
5. При необходимости собрать немного реальных скриншотов и дообучить модель.

## Важные решения по логике

- Игрок всегда находится внизу доски.
- Когда играешь чёрными — белые ходят первыми. Система должна увидеть ход белых и только потом предлагать ответ за чёрных.
- Главное узкое место сейчас — качество зрения, а не сила Stockfish.
- Предпочитаем маленькую и быструю модель (дистиллированный CNN) для работы в реальном времени на MacBook Air M2 8 ГБ.
