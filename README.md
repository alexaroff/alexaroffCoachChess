# alexaroffCoachChess

Десктоп-приложение для macOS — шахматный **тренер** (Coach) поверх доски на экране.  
Главная цель — **Duolingo Chess**.

## Цель проекта

Давать точные стрелки-подсказки в реальной партии:
- Игрок всегда сидит снизу
- Можно играть и белыми, и чёрными
- Система должна правильно понимать, чей сейчас ход
- Stockfish (~3000 Elo) используется только как источник сильного хода

Режим Auto (автоигра) в коде есть, но сейчас **не приоритет**.

---

## Текущий статус (26 июля 2026, 12:50 CEST)

### Что сделано

- Полный прототип: захват экрана, выбор области (двухкликовый), ориентация, Stockfish, overlay со стрелками, hybrid reconcile.
- Template matching **отброшен**.
- Перешли на **TinyCNN**.
- Полный синтетический датасет 4600 картинок есть.
- Модель обучена на полном датасете → `val_acc = 1.000` **на синтетике**.
- Выбор области: **два клика через pyautogui** (надёжнее fullscreen Tk).
- Защита королей в классификаторе (чтобы Stockfish не отказывался).

### Главная текущая проблема

Модель, обученная **только на синтетических шаблонах**, плохо работает на реальных скриншотах Duolingo.  
Из-за этого:
- Фигуры часто распознаются неправильно
- Стрелки уезжают
- Reconcile не всегда спасает

### Что нужно сделать дальше (когда будет сила)

1. Собрать реальные клетки с доски Duolingo (скрипт нарезки + ручная проверка).
2. Дообучить TinyCNN на смеси синтетики + реальных клеток.
3. После этого снова тестировать на реальных партиях.

### Окружение пользователя

- MacBook Air M2
- Python 3.12 (Homebrew) + venv в корне проекта
- Установлено: torch, numpy, Pillow, python-chess, mss, pyautogui
- Права: Запись экрана + Универсальный доступ выданы Terminal

### Как запускать

```bash
cd ~/alexaroffCoachChess
source venv/bin/activate
git pull origin main
python main.py
```

При выборе области — инструкции появляются в терминале (два клика мышью + Enter).
