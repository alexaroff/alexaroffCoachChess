# alexaroffCoachChess

Десктоп-приложение для macOS — шахматный **тренер** (Coach), который работает поверх доски на экране.  
Главная цель — **Duolingo Chess**.

## Цель проекта

Давать точные стрелки-подсказки в реальной партии:
- Игрок всегда сидит снизу
- Можно играть и белыми, и чёрными
- Система должна правильно понимать, чей сейчас ход
- Stockfish (~3000 Elo) используется только как источник сильного хода

Режим Auto (автоигра) в коде есть, но сейчас **не приоритет**.

## Текущий статус (26 июля 2026)

### Что уже сделано

- Полностью рабочий прототип: захват экрана, выбор области, фиксация ориентации, Stockfish, overlay со стрелками, hybrid reconcile.
- Подход на template matching был тщательно протестирован и **отброшен** — он не способен стабильно держать позицию после нескольких ходов на стилизованной доске Duolingo.
- Принято решение переходить на **нейросеть** для распознавания фигур (Вариант A).
- **Синтетический датасет** сгенерирован (в sandbox — уменьшенная версия ~580 изображений для быстрого обучения; на машине пользователя можно перегенерировать полный 4600).
- **TinyCNN** обучен до **val_acc = 1.000** на синтетике.
- Модель **встроена** в `board_detector.py` (с fallback на старые шаблоны).

## Важные решения по логике

- Игрок всегда находится внизу доски.
- Когда играешь чёрными — белые ходят первыми. Система должна увидеть ход белых и только потом предлагать ответ за чёрных.
- Главное узкое место сейчас — качество зрения, а не сила Stockfish.
- Предпочитаем маленькую и быструю модель (TinyCNN ~100k params) для работы в реальном времени на MacBook Air M2 8 ГБ.
